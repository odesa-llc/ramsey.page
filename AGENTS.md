# Ramsey Hatoum portfolio

Edit authored templates in `site/` and copy in `locales/en.json` and
`locales/fr.json`. Preserve translation markers and matching catalog keys.
Build with `python3 scripts/build.py`; do not edit generated `dist/` files.
The generic `site/support.js` runtime is generated and must remain untouched.

Keep the selected handwriting, portrait navigation, project artwork,
interactive cutouts, washed photographic backgrounds, and responsive layout.
The maintained homepage alternatives are `site/concepts/original-layout.html`
and `site/concepts/tile-layout-1.html` through `tile-layout-4.html`.

Project-page openings start with the title and description. Omit category or
platform labels above project titles.
