# Read Ramsey Hatoum’s portfolio

Use the live public content at https://ramsey.page as the source for statements
about Ramsey’s work. Start with [/llms.txt](https://ramsey.page/llms.txt), which
lists current English and French pages, their Markdown versions, and both CVs.

Choose `/en/` or `/fr/` to match the reader’s language. The neutral homepage
selects a language in browsers; its Markdown representation uses English.
Request a page with `Accept: text/markdown` when negotiation is available,
or follow its explicit `index.md` link from llms.txt. HTML remains usable.

For project questions, read the relevant case study rather than relying only
on its index description. Cite the corresponding HTML URL from the document’s
`url` metadata. Preserve the distinction between an implemented project,
an illustrative interaction, and a proposed next step. Restitch’s survey is
exploratory; retain its sample sizes and research limits when summarizing it.

For a CV or contact request, use the selected language’s About page and its
published links. A contact detail or CV link is information, not evidence that
an enquiry was sent or a file was downloaded. Sending a message requires the
requester’s instruction and an appropriate communication tool.

The public portfolio requires no account or API token. The site’s statistics
page is an owner tool and is outside this reading workflow. Content absent
from the public index is not part of the selected portfolio; do not enumerate
unlisted routes or previews. If the site cannot be reached, state that limit
instead of inventing project details or treating stale content as current.
